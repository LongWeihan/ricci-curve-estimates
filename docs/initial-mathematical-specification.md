## 2. 实际几何输入与主定理

令 M 是有限维光滑无边界紧流形，g(t) 是 I=[t₀,T] 上光滑正定 Riemannian metric family，满足 ∂ₜg=−2 Ric(g)。取任意 τ≤T，以及实际映射 c:(ℝ/ℤ)×[t₀,τ)→M。每一闭子区间 [t₀,b] 上，c 与 g 均光滑至端点（可用局部光滑延拓表达），cₓ≠0，且 ∂ₜc=∇^{g(t)}_S S。光滑存在和该方程允许作为输入；不假设几何微分不等式、不假设曲率有界至 τ、不证明延拓。

所有沿 c 的向量、联络和张量均在 pullback bundle 上定义，不把自交曲线的像当作嵌入子流形。用 ℝ 上 1-周期局部 lift 定义：

- X=dc(∂ₓ)，v=√g(X,X)>0，S=X/v，Dₛf=v⁻¹∂ₓf。
- H=∇^g_S S，q=g(H,H)，k=√q；k 仅连续/局部 Lipschitz，q 光滑。
- ds=v dx；L(t)=∫₀¹v dx；Θ(t)=∫₀¹kv dx；E(t)=∫₀¹qv dx。
- ĝ=g(t)+dt²，Tvec=∂ₜ，Ĥ=dĉ(∂ₜ)=H+Tvec，ĉ=(c,t)。记 ∇̂ 为 ĝ 联络。
- P=∇̂_S H−⟨∇̂_S H,S⟩S；这是 spacetime bundle 中正交于 S 的投影，不能悄悄替换成纯水平法向导数。

环境常数取 B,D,Kₕ,Kₘ≥0，分别控制所有相关点上的 Ric 双线性算子范数、∇^g Ric 三线性算子范数、ĝ 曲率四水平分量、以及 ĝ 曲率一个 Tvec 三个水平分量。即 |R̂(A,B,C,Dv)|≤Kₕ|A||B||C||Dv|，|R̂(Tvec,B,C,Dv)|≤Kₘ|B||C||Dv|，水平向量任意。常数可由光滑性与紧性取得；产品推广应直接证明这些分量界稳定，而不诉诸缩小圆的 injectivity radius。

设 A₀=6B+2Kₕ+2B²，A₁=2Kₘ+2D，Ĉ=max(A₀,A₁)，C₁=Ĉ/2，C₂=B，C=C₁+C₂。**主定理**：以上实际几何输入蕴含，对任意 t₀≤s≤t<τ，

    L(t) ≤ L(s) exp(B(t−s)),
    Θ(t)+L(t) ≤ (Θ(s)+L(s)) exp(C(t−s)),
    Θ(t) ≤ (Θ(s)+L(s)) exp(C(t−s)).

并且

    ∫ₛᵗ exp(−B(r−s)) E(r) dr ≤ L(s)−exp(−B(t−s))L(t),
    ∫ₛᵗ E(r) dr ≤ exp(B(t−s))L(s)−L(t).

若 c 光滑浸入至闭端点 τ，则同样允许 t=τ；否则只能给出 t↑τ 的 limsup 数值界，不能声称存在 c(τ)。时间平移应是定理的一般参数，避免固定起点 0 后反复适配。

## 3. 十一个局部验收引理

### G1. 单位切向与 pullback 协变微分

输入：实际 c,g 及浸入性，不需曲线流方程。输出：v>0、⟨S,S⟩=1、⟨H,S⟩=0、∇^g_X X=v²H+(∂ₓv)S，以及固定 x,t 的 pullback 联络 Leibniz/metric compatibility。必须区分 ∂ₜ（固定参数 x）与 Dₛ（随时间改变）。

### G2. 时空联络与环境曲率分量

输入：实际 ĝ 及 Ricci flow 方程。输出：∇̂_A B=∇^g_A B+Ric(A,B)Tvec；∇̂_A Tvec=−Ric♯(A)；∇̂_{Tvec}Tvec=0；水平 Christoffel 与混合 Christoffel 公式。进一步由 Gauss/Codazzi 型计算建立 Kₕ 由 |Rm(g)|、|Ric|² 控制，Kₘ 由 |∇Ric| 控制；这些是需要证明的张量恒等式/界，不是最终曲线演化的假设。

实现时固定符号约定 R̂(A,B,C,Dv)=⟨(∇̂_A∇̂_B−∇̂_B∇̂_A−∇̂_[A,B])Dv,C⟩，或给出与 Lean 库 convention 的明确翻译。

### G3. 速度、交换子与弧长演化

输入：G1、G2、∂ₜc=H。输出：∂ₜ(v²)=−2Ric(X,X)−2qv²；∂ₜv=−(q+Ric(S,S))v；[Ĥ,S]=(q+Ric(S,S))S；对标量 f 有 [∂ₜ,Dₛ]f=(q+Ric(S,S))Dₛf。作为密度恒等式写出 ∂ₜds=−(q+Ric(S,S))ds，避免把 ds 当作实数。

### G4. 完整平方曲率演化

输入：G1–G3 与 ∇̂ 曲率交换恒等式。输出（所有项逐项证明）：

    ∂ₜq = Dₛ²q − 2|P|² + 2q²
           −2Ric(H,H) +4q Ric(S,S)
           +2R̂(Ĥ,S,H,S)
           +2Ric(S,S)Ric(H,H) −2(∇^g_S Ric)(S,H).

内部需证明 ⟨∇̂_S H,S⟩=−q 及 |∇̂_S H|²=|P|²+q²。单纯把此公式放进 `FlowData` 字段不能验收本引理。

### A1. 环境误差吸收

输入：G4 及上述真实环境张量范数界。输出：∂ₜq≤Dₛ²q−2|P|²+2q²+Ĉ(q+k)。分开估计 R̂(H+Tvec,S,H,S)，分别给出 Kₕk² 和 Kₘk；不可把 Ĥ 的长度当作 k。

### A2. ε 正则化及全点 Kato 型界

输入：q=|H|²、P 的真实定义、A1；任意 ε>0。定义 hε=√(q+ε²)。输出：hε>0、k≤hε≤k+ε；Dₛhε=⟨P,H⟩/hε；|Dₛhε|²≤|P|²；以及

    ∂ₜhε ≤ Dₛ²hε + k³ + C₁(hε+1).

无需区分 k=0，也不对 k 在零点求导。代数核心：k⁴/hε≤k³，k²/hε≤hε，k/hε≤1。

### A3. 移动密度微分与周期积分消项

输入：光滑周期 f(x,t)、G3。输出：d/dt∫₀¹fv dx=∫₀¹(∂ₜf−f(q+Ric(S,S)))v dx；∫₀¹(Dₛ²f)v dx=0。后二阶消项来自 (Dₛ²f)v=∂ₓ(Dₛf) 与周期性；不依赖把 x 误当作弧长。证明 differentiation under integral 时应给出任意紧时间矩形上连续导数的统一支配。

### A4. 正则化耦合积分估计

输入：A2、A3；定义 Θε=∫hε ds。输出：L'=−E−∫Ric(S,S)ds≤BL−E；Θε'≤CΘε+C₁L。关键有利项 k³−hε k²≤0。此处仍是 ε>0 下的经典导数。

### A5. ε 极限、连续性与导数语义

输入：实际 q,v 光滑，以及 A4。输出：0≤Θε−Θ≤εL，在任意紧时间段上一致收敛；对任意 s≤t 有

    Θ(t)−Θ(s) ≤ ∫ₛᵗ (CΘ(r)+C₁L(r)) dr.

因此在每个 t<τ 有上右 Dini 导数 D⁺Θ(t)≤CΘ(t)+C₁L(t)。证明先积分，再用一致误差界过极限，最后以右差商得到 Dini 界，不能交换极限与导数。

另可证明 Θ 在紧时间段上 Lipschitz（故绝对连续）：沿每条固定 x 的时空曲线平行运输 H，用 |d|H|/dt|≤|∇̂_{Ĥ}H| 的范数 Lipschitz 论证，再结合 v 的界。单边积分不等式本身不蕴含绝对连续。AC 版本导出 a.e. 的 Θ' 界，但最终指数比较不必依赖此额外 API。

### A6. 标量比较与能量积分

输入可抽象为非负连续 L,Θ、L 的经典微分界及 A5 的全区间积分界；这是独立分析引理的合法输入，不是根几何定理假设。输出第 2 节全部估计。可选最省库依赖路线：先对光滑 Zε=Θε+L 用经典 integrating factor 得 Zε(t)≤Zε(s)e^{C(t−s)}，再取 ε→0；如此最终 bound 不需要 Dini/AC 理论。L 的积分因子给加权能量式；无权式由 L'=−E−∫Ric 和 L 的指数界积分得到，B=0 时避免除以 B。

### U1. 产品圆与任意索引族统一化

输入：Wλ=M×(ℝ/λℤ)，metric g(t)+dy²，λ>0；任意索引类型 A；每个 (a,λ) 给实际光滑浸入曲线流 c_{a,λ}，共同时间区间或逐个存在时间 τ(a,λ)，共同初始上界 L₀,Θ₀≥0。

输出：产品 metric 仍为 Ricci flow；上述 B,D,Kₕ,Kₘ 可选择为同一 base-flow 常数，因为 circle directions 的 curvature/connection contribution 为零，时空产品是 (M×I,ĝ)×S¹λ（交换因子后）。然后对所有 a、λ、合法 t：

    L_{a,λ}(t)≤L₀e^{B(t−t₀)},
    Θ_{a,λ}(t)+L_{a,λ}(t)≤(Θ₀+L₀)e^{C(t−t₀)}.

不要求 A 紧、不要求关于 a 连续；这些只在从具体 Γ 推出共同初始界、构造连续变形时需要。λ→0 本身不属于浸入/环境定理的参数值。ramp 的 u>0、统一正下界、存在与延拓均非本结论必要假设。若上游给 smoothing/ramp approximation，则其共同初始界必须有独立证据；不能声称任意紧 C⁰ loop family 自动具有统一曲率界。

## 4. 修正项逐项审计

- 两个交换子项各产生 2(q+Ric(S,S))q，与切向分解的 −2q² 合并为 +2q²+4q Ric(S,S)。
- ∇̂_S∇̂_S Tvec 的水平部分贡献 −2Ric(H,H)−2(∇^g_S Ric)(S,H)。后项是 O(k)，正则化后造成常数 forcing，积分后造成长度项。
- 从 H=∇̂_S S−Ric(S,S)Tvec 求时间导数，vertical coefficient 的导数与水平 H 内积为零，但 ∇̂_{Ĥ}Tvec 非零；留下 +2Ric(S,S)Ric(H,H)。不能删除整个乘积导数。
- 协变导数交换用的是 ĝ 的 R̂(Ĥ,S,H,S)。R̂(Tvec,S,H,S) 又提供 O(k)。把 ĝ 换回 g 或把 Ĥ 换成 H 会丢项。
- P 含可能的 vertical 分量。把它替换成 ∇^g 的投影需要同时重写其平方与其他误差项；当前验收按 ĝ 版本统一。

## 5. 真正的下游接口与排除项

本模块应实际导出 E 的时间积分控制：它由长度恒等式几乎免费得到，是 good-time selection 的输入。还应导出任意子区间积分 Θ 的粗界，可供 swept-area Jacobian =k ds dt 的后续模块调用。局部加权总曲率估计使用 A2+A3 并增加 cutoff 项；常数必须携带 L₀,Θ₀。这里不承诺证明 local smoothing、good-time 紧致性、最小盘面积演化、有限消失或庞加莱定理。

族常数 uniform 指 B,D,Kₕ,Kₘ 不依赖 a,λ，L₀,Θ₀ 是上游共同初始数据；从紧 ambient 自动取得的每条曲线局部导数界只是积分/极限证明的辅助界，可以依赖该条曲线与紧时间段，不能混进最终 C。
