4/-!
5# Smooth curve-shortening flow: geometric input
6
7The curve family is `c t x`, with period one in `x`. Only smooth existence,
8immersion, closure and the defining curve-shortening equation are inputs.
9No speed, curvature or integral evolution estimate is part of this predicate.
10
11Time derivatives in the input are within the time set. This avoids imposing
12an artificial extension of the PDE before an initial time or beyond a final
13time. At interior times the equation gives the ordinary chart derivative.
14-/

30/-- A genuine smooth immersed closed curve-shortening flow in a metric family.
31The Ricci-flow equation for the metric is a separate upstream predicate. -/
32structure IsCurveShorteningFlowOn (g : ℝ → Riemannian.RiemannianMetric I M)
33 (c : ℝ → ℝ → M) (J : Set ℝ) : Prop where
34 smooth : ContMDiffOn (𝓘(ℝ, ℝ).prod 𝓘(ℝ, ℝ)) I ∞
35 (fun p : ℝ × ℝ => c p.1 p.2) (J ×ˢ (Set.univ : Set ℝ))
36 closed : ∀ t ∈ J, IsClosedCurve (c t)
37 immersed : ∀ t ∈ J, ∀ x, curveVelocity (I := I) (c t) x ≠ 0
38 equation : ∀ t ∈ J, ∀ x,
39 HasDerivWithinAt (chartLocalCurve (I := I) (fun s => c s x) t)
40 (curvatureVector (g t) (c t) x) J t
